Agent orchestrator / flow

Một yêu cầu, hai worker độc lập

OpenCode Desktop giữ vai trò điều phối: chia việc, gọi MCP, theo dõi kết quả và duyệt diff. Mỗi CLI chỉ làm việc trong worktree của tác vụ mình.

Dashboard chỉ đọc báo cáo trong Git metadata để hiển thị worker, model, trạng thái và test. Nó không dispatch hoặc thay đổi run.

1. Giao việc

Dùng skill parallel-cli-orchestration để lập tác vụ độc lập, chọn worker, phạm vi file và lệnh test được phép.

2. Theo dõi

Gọi get_run_status, hoặc mở dashboard tại 127.0.0.1:4317 cho cùng Git repository.

3. Duyệt kết quả

collect_run_results cho báo cáo; kiểm tra git diff <base_commit> trong từng worktree trước khi chấp nhận.

4. Dừng / dọn

cancel_run giữ worktree. cleanup_run chỉ chạy sau yêu cầu rõ ràng; không xóa branch hay dữ liệu chưa commit.
